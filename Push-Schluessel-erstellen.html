Push-Schlüssel erstellen

Diese Datei lokal im Browser öffnen. Sie stellt keine Netzwerkverbindung her. Einmal erzeugen und dieselben Schlüssel behalten; ein Wechsel erfordert eine erneute Aktivierung auf allen Geräten.

Die beiden geheimen Werte ausschließlich in Supabase hinterlegen. Nicht in GitHub oder Chat einfügen. Beim Schließen dieser Datei werden die Werte nicht gespeichert. Sicher aufbewahren, beispielsweise im Passwortmanager.
